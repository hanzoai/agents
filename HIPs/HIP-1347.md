## Abstract
This HIP proposes a mandatory context-packing strategy for Hanzo Agents to mitigate the "Lost in the Middle" phenomenon, ensuring high retrieval accuracy regardless of document volume.

## Motivation
Current Hanzo agents (Zen/Kai) utilize a linear relevance packing strategy. Research shows this leads to significant information loss when the context window exceeds 4k tokens and the relevant "needle" is not at the boundaries.

## Specification
All components implementing the `context-manager` definition MUST support `u-shape-ranker` as an optional or default packing mode.

### U-Shape Algorithm:
Given a list of documents $D$ sorted by relevance score $S$:
1. Initialize empty list $R$.
2. For each $d_i$ in $D$:
   - If $i$ is even: Append $d_i$ to the front of $R$.
   - If $i$ is odd: Append $d_i$ to the back of $R$.
3. Return $R$.

## Rationale
This approach maximizes the utilization of the model's attention mechanism at both the primacy and recency boundaries without requiring model fine-tuning.

## Backwards Compatibility
No breaking changes. This is a logic update within the `context-manager` agent.
